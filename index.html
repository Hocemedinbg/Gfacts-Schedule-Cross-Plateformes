🔒 Guide — stocker les tokens en secrets du dépôt
  1. Dépôt → Settings → Secrets and variables → Actions → New repository secret : GH_TOKEN (votre PAT) puis OPENROUTER_API_KEY (votre clé OpenRouter).
  2. Créez le fichier .github/workflows/inject-secrets.yml (contenu fourni dans la documentation de l'app).
  3. Onglet Actions → "Inject secrets" → Run workflow : il génère config/runtime-config.json dans le dépôt.
  4. Rechargez l'application : les tokens sont chargés automatiquement, tous les champs de clé peuvent rester vides.

⚠️ Le dépôt doit rester PRIVÉ : le fichier généré contient les tokens. Utilisez un PAT "fine-grained" limité à ce dépôt uniquement.
